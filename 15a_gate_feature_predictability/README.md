# Task 15A — pre-second-hop gate feature predictability

CPU-only post-hoc analysis of frozen Task 12/14 outputs. It asks whether features
available before a second-hop query can identify samples whose true-label rank
could be improved by second-hop evidence. Ground truth is used only to define the
analysis target, never as an inference input. Outputs are diagnostic and cannot
be used to select a final threshold on the six test sets.

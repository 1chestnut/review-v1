# 实体映射协议 v2（严格版）

## 目的

把六个数据集的候选类别名称连接到当前 AKG 实体。映射只解决词面差异，不利用音频、真实标签排名或测试集性能。无法证明语义等价时保留未映射，模型对该类别继续使用原始 CLAP 分数。

## 冻结规则与顺序

1. `exact_normalized`：仅进行小写化、下划线转空格、首尾空格和固定标点规范化；规范化结果必须与一个 AKG 实体名称完全相同。
2. `unique_token_signature`：按固定规则去除连接符并规范化词元后，必须只有一个 AKG 实体具有完全相同的内容词集合。存在多个候选、只共享部分词或概念范围改变时不采用。
3. `historical_reproduction_map`：仅保留旧复现中已经存在、且可以确认指向同一声音概念的固定别名。它单独标记，不能称为 iKnow 官方映射。
4. `unmapped`：前三条均不能证明等价。禁止取第一个词、最后一个词、模糊字符串最近邻或更宽泛的上位概念来强制命中。

## 禁止依据

- 不看某个映射能否提高 Hit@K 或 MRR；
- 不根据测试结果在多个候选实体中选择；
- 不把近似概念当作同义词，例如 `tram → train`、`power windows → window`；
- 不删除未映射类别及其测试样本；
- 不为 iKnow、Full 和 Ours 分别建立不同映射。

## 未映射时的推理行为

候选类别没有可靠 KG 实体时，不执行该类别的知识查询：

`s_KG(c) = s_CLAP(c)`

该类别和对应样本仍参与完整数据集评价。最终同时报告静态类别覆盖率，以及实际 Top-K 候选的 `mapped_topk/unmapped_topk`。

## 文件说明

- `entity_mapping_v2_full_audit.csv`：819类完整表，包含原标签、KG实体、决定、依据和失败行为。
- `entity_mapping_v2.json`：供严格映射版实验读取。
- `mapping_summary_v2.csv/json`：逐数据集覆盖统计。

本协议由旧映射 v1 复制并补充审计字段形成，未覆盖旧文件。若以后找到新的官方同义词证据，应产生 v3，而不能原地修改 v2。

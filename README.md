# review-v1

Reproducibility and reviewer-response experiment code for the iKnow audio project.

## Directory sequence

- `01clap-iknow`: historical one-hop reproduction.
- `02clap-iknow-strict-map-v2`: auditable class-to-KG entity mapping experiment.
- `03_full-second-hop-pilot`: initial full second-hop pilot.
- `04_iknow-km-reproduction-audit`: one-hop K/M audit.
- `05_frozen-k5m3-strict-comparison`: historical comparison snapshot; see its protocol notes before reuse.
- `05b_strict-map-k5m3-freeze`: corrected strict-mapping K=5, M=3 one-hop freeze.
- `06_onehop-text-verbalization-audit`: controlled one-hop verbalization comparison.
- `07_second-hop-mp-audit`: paused second-hop M2/P audit.

Generated embeddings, progress files, logs, large per-sample JSON outputs, datasets, and model weights are intentionally excluded. Compact result tables and protocol documentation are retained.

# 实验部分术语表（中文初稿）

| 统一写法 | 首次说明/边界 |
|---|---|
| 零样本音频分类 | 候选类别在目标任务中不用于模型参数训练；开发集超参数选择仍需单独披露。 |
| CLAP | 冻结的音频—文本对比预训练模型；不是同名的其他领域方法。 |
| iKnow复现基线 | 当前代码冻结的单跳知识增强实现；不是原作者未公开代码的逐项精确复刻。 |
| AAKV | 受约束的音频感知知识语言化；离线生成文本，需报告验证与回退。 |
| Fusion | 原始CLAP分数与知识增强分数的分层融合；本实验固定α=0.3。 |
| Selector | 标签不可知的样本级关系选择；每样本保留N_r=5种关系。 |
| TFS完整方法 | AAKV、Fusion、Selector三模块组合；仅使用一跳。 |
| Hit@1/3/5、MRR | 全部按真实标签的最优名次计算；多标签样本取所有正标签中排名最高者。 |
| DCASE17-T4 | 419条可用样本，作为方法级参数开发集；不进入最终测试主表。 |
| TUT2017 | 当前4,680条来自development/meta.txt；不能未经核对称为官方evaluation测试集。 |

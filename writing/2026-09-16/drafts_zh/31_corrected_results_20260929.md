# 统一 AAKV 缓存后的结果核查与正文修订稿

数据来源：`31_corrected_aakv_cache` 中完成的 FSD50K（10,231 条）和 AudioSet（17,233 条）完整因子消融、关系选择对照及逐样本统计。ESC-50、UrbanSound8K、TUT2017 沿用已锁定结果。DCASE17-T4 开发集重新核对后仍选定 `alpha=0.3, N_r=5`。

## 关键更正

- FSD50K 完整方法：Hit@1 64.46%，Hit@3 80.52%，Hit@5 86.48%，MRR 74.13%。
- AudioSet 完整方法：Hit@1 31.29%，Hit@3 46.90%，Hit@5 54.80%，MRR 42.56%。
- 五数据集等权平均：完整方法 Hit@1 66.81%，MRR 75.08%；AAKV＋关系选择 Hit@1 65.81%，MRR 74.41%。
- FSD50K 的 AAKV＋关系选择 Hit@1 为 64.49%，比完整方法 64.46% 高 0.03 个百分点；完整方法在该数据集的 MRR 仍较高。因此不得再写“完整方法在五个数据集的 Hit@1 和 MRR 均优于所有消融配置”。
- 相较 iKnow†，五集 Hit@1 增益范围改为 2.08–12.73 个百分点，MRR 增益范围改为 1.02–6.68 个百分点。
- 关系选择对照的五集等权平均 Hit@1/MRR：FrozenRq 64.44/73.98，Frequency Top-5 64.25/73.82，Random Top-5 64.75/74.13，Selector 66.81/75.08。
- 预测转移：FSD50K 错转对 991、对转错 518，净改善 473；AudioSet 为 1131、773，净改善 358。五个数据集的 McNemar 检验经五项 Holm 校正后仍小于 0.05，且 Hit@1/MRR 的 95% Bootstrap 区间仍未跨零。

## 正文修订措辞

### 总体结果

本文方法在五个测试集的 Hit@1 和 MRR 上均高于 CLAP 与 iKnow†。与 iKnow† 相比，Hit@1 和 MRR 的提升范围分别为 2.08–12.73 和 1.02–6.68 个百分点。FSD50K 上两项指标分别提高 4.62 和 2.33 个百分点；除 TUT2017 外，其余三个数据集的 Hit@1 提升为 2.08–2.50 个百分点，MRR 提升为 1.02–1.18 个百分点。

### 完整因子消融

三种双模块配置中，AAKV 与样本级关系选择组合的五数据集等权平均 Hit@1 和 MRR 最高，分别为 65.81% 和 74.41%。以分层融合与样本级关系选择的组合为参照，加入 AAKV 后，完整方法的等权平均 Hit@1 从 63.63% 提高至 66.81%，MRR 从 73.31% 提高至 75.08%，增益分别为 3.18 和 1.77 个百分点。完整方法获得最高的五数据集等权平均 Hit@1 和 MRR，但并非每个单项指标都最高：FSD50K 上，AAKV 与关系选择组合的 Hit@1 为 64.49%，略高于完整方法的 64.46%；后者的 MRR 则从 74.02% 提高至 74.13%。这一结果表明，第三个模块并非在所有数据集的每个指标上都带来增益，应将主要结论限定为总体表现和所比较配置下的互补作用。

### 关系选择分析

关系选择器在五个数据集的 Hit@1 和 MRR 上均为最佳。其五数据集等权平均值为 66.81% 和 75.08%，相较 FrozenRq、Frequency Top-5、Random Top-5，Hit@1 分别提高 2.37、2.56、2.06 个百分点，MRR 分别提高 1.10、1.26、0.95 个百分点。

### 知识语言化分析

在固定关系选择与融合规则后，AAKV 的五数据集等权平均 Hit@1 为 66.81%，相较直接拼接与原始三元组文本分别提高 3.18 和 3.35 个百分点；MRR 为 75.08%，分别提高 1.77 和 2.17 个百分点。以直接拼接为参照，AAKV 在 FSD50K 和 TUT2017 的 Hit@1 分别提高 3.86 和 9.00 个百分点。

### 统计与逐样本分析

FSD50K 和 AudioSet 相较 iKnow† 的 Hit@1 增益分别为 4.62 和 2.08 个百分点；对应的 95% 成对 Bootstrap 区间分别为 [3.87, 5.36] 和 [1.56, 2.58]。五集 Hit@1 与 MRR 的差值及区间均保持正值。FSD50K 和 AudioSet 的净正确样本增量分别改为 473 和 358。

## 边界

现有计算成本实验使用旧缓存版本；此次修订不将新的分类结果外推为新的延迟或缓存规模数值。若最终稿要求所有实验均基于同一缓存版本，需对成本实验另行核对。本文不据此宣称完整配置在所有单项消融比较中都最佳。

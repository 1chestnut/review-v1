# Task 14 — second-hop AAKV and M2/P potential audit

This task runs two strictly separated analyses in one queued pipeline.

1. Task 14A compares the Task 13 deterministic fallback sentence with a second-edge
   sentence generated by exactly the frozen Task 10 AAKV prompt/validator. Paths,
   M2=1, P=5, gamma=0.85 and all scoring are identical.
2. Task 14B freezes AAKV and evaluates M2={1,3,5} x shared total P={3,5,10}.
   Each two-hop configuration is compared only with its matched one-hop P baseline.

K=5, M1=3, gamma=0.85, relations, aggregation, dynamic alpha and deterministic
Task 12 audio embeddings are frozen. No gate is used. This is an exploratory
potential audit, not a final test-set hyperparameter-selection protocol.

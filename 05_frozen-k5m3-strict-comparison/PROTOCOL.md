# 任务05：严格映射与统一K5M3下的一跳—全量二跳重新冻结比较

## 冻结基础

- 类别—KG实体映射：任务02严格映射v2；未确认类别保持CLAP分数，不做不可靠单词回退。
- 关系集合：逐数据集复制任务01，且一跳和二跳使用完全相同的关系集合。
- 全六集统一Top-K=5、Top-M=3；二跳查询同样每个`(head, relation)`保留M=3。
- 类别提示、数据处理、多标签评价、CLAP、KGE与任务02一致。
- 一跳、二跳知识文本统一为直接拼接`class_name, tail`。
- 静态缓存KG路径和CLAP文本嵌入，不缓存音频—知识文本相似度。

## 四列

1. `CLAP`：无知识。
2. `iKnow-1st`：严格映射、K5M3、任务01关系集合，一跳联合NormLSE100。
3. `Ours-1st`：相同一跳证据，使用`alpha*base+(1-alpha)*LME100(TopP(h1))`。
4. `2nd-Full`：相对Ours-1st只加入全量二跳证据，公式为`alpha*base+(1-alpha)*LME100(TopP(h1 union 0.85*h2))`。

探索参数仍为Top-P=5、gamma=0.85、动态alpha范围[0.4,0.8]。本任务不包含delta门控或选择性二跳。

## 解释边界

- `iKnow-1st−CLAP`用于冻结统一K5M3的一跳复现。
- `Ours-1st−iKnow-1st`用于检查新一跳融合组合。
- `2nd-Full−Ours-1st`用于检查同一冻结基础下完整全量二跳组合的净变化。
- 完整二跳仍同时包含二跳深度和gamma=0.85；若有增益，后续再以gamma=1.0对照拆分。

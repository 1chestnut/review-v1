## 当前结论

- 新融合组合在5/6个数据集取得正Hit@1变化。
- 全量二跳在2/6个数据集取得超过0.05个百分点的Hit@1增益；其余为近零或下降。
- 全量二跳六集宏平均变化：ΔHit@1=-0.10，ΔMRR=+0.00。
